# 데이터 안내

이 폴더는 공개 가능한 샘플 데이터와 데이터 구조 설명을 두기 위한 공간이다.

원본 데이터는 당시 팀 작업 공간과 Drive에 분산되어 있었다. 해당 작업 공간은 이 공개 저장소에 포함하지 않는다.

## 주요 데이터

- `data/sample/`: GitHub에서 바로 확인할 수 있는 소형 OHLCV 샘플 CSV.
- 원본 일봉·뉴스 데이터: 외부 소스, 당시 수집 시점, 로컬 DB 상태에 의존하므로 공개 저장소에는 포함하지 않는다.

## 공개 주의

DB 파일, 실행 파일, 체크포인트, 개인정보성 자료와 전체 원본 데이터는 Git 추적 대상에서 제외한다.
